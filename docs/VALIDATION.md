# Проверка артефактов

- Полная серия: 40 запусков, 20 для каждого метода.
- Фактические бюджеты всех запусков совпадают с конфигурацией.
- Финальные значения пересчитаны из сохранённых решений.
- Проверены ограничения, монотонность лучшего значения и структура архивов.
- Один seed каждого метода повторён из постороннего рабочего каталога: все поля, кроме времени, совпали с полной серией.
- CLI отклоняет --runs 0 с кодом 2.
- Модульные проверки: см. TEST_LOG.txt.

Проверка выполнена в Python 3.12.14. Это подтверждение проверенных сценариев, а не формальная гарантия отсутствия любых ошибок во всех средах.
