# К защите

Суть: выбираем количество каждого товара. Больше закупаем — обычно меньше дефицит, но выше затраты и остатки. Поэтому единственного лучшего плана без предпочтений заказчика нет.

Доминирование: не хуже по всем трём критериям и строго лучше хотя бы по одному. Crowding сохраняет разнесённые точки фронта. Внешний архив не теряет найденные компромиссы при обновлении популяции.

Почему свёртка лучше по score? Она прямо оптимизирует один score; NSGA-II ищет множество альтернатив. По одному score нельзя судить обо всём фронте.

Что такое CVaR? Средний взвешенный дефицит в шести худших сценариях из шестидесяти. Это тяжесть нехватки, не вероятность.
